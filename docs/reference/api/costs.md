# Cost Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | `/api/v1/costs/dashboard` | Cost dashboard — total spend, utilisation, breakdowns, daily trend |
| GET | `/api/v1/costs/recommendations` | AI-powered cost optimisation recommendations |
| POST | `/api/v1/costs/budgets` | Create a budget |
| GET | `/api/v1/costs/budgets` | List budgets |
